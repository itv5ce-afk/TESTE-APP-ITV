Como aplicar no seu site (GitHub Pages):
  1. Abra o index.html do repositório iPlay-Store no GitHub.
  2. Clique no ✏️ para editar.
  3. Localize o <head> e cole o código gerado logo abaixo.
  4. Se já existir uma linha com rel="icon", substitua-a.
  5. Clique em Commit changes e aguarde ~1 min.
  6. Recarregue a aba com Ctrl+Shift+R para ver o novo ícone.
